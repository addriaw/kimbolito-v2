# KIMBOLITO V2

Sistema IoT full-stack para monitoreo y alimentación automática de un hámster mediante ESP32, MQTT, FastAPI y Next.js.

## Arquitectura
- Frontend: Next.js + TypeScript
- Backend: FastAPI + SQLAlchemy
- Base de datos: PostgreSQL
- Mensajería IoT: MQTT
- Automatización: scheduler para alimentaciones programadas
- Notificaciones: Web Push y WhatsApp

## Estructura
- `frontend/`: aplicación web
- `backend/`: API, modelos, rutas y servicios
- `config/`: configuraciones de ejemplo

## Seguridad
El paquete del proyecto fue preparado para publicación evitando credenciales reales, claves privadas, backups de base de datos, entornos virtuales y archivos generados.

## Instalación
Consulta el proyecto incluido en `project-source/kimbolito-v2-github-ready.zip`. El paquete contiene la estructura limpia y archivos de ejemplo para configurar el entorno.
